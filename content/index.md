# Медицинский архив

Структурированный архив медицинских документов ребёнка: выписки, консультации, лабораторные и инструментальные исследования за **2020–2026 годы**. Все документы переведены из PDF и DOCX в заметки, названия которых строятся по схеме `ГГГГ-ММ-ДД_Тип-исследования_Учреждение`.

> [!warning] Важно
> Заметки созданы по сканам оригиналов, часть рукописных бланков распознана с неполной уверенностью (такие места помечены в тексте). Архив не заменяет консультацию врача. При расхождениях ориентируйтесь на оригинальные документы.

## С чего начать

- [[2026-09-13_Сводка-для-гастроэнтеролога|Сводка для гастроэнтеролога]] — клиническая картина целиком: диагнозы, хронология, динамика показателей, открытые вопросы.

## Как пользоваться сайтом

- **Поиск** (значок лупы или клавиша `/`) работает по всем заметкам: можно искать по дате, названию анализа или учреждению.
- **Теги и папки** в боковой панели позволяют отобрать документы одного типа.
- **Граф связей** показывает, как документы связаны между собой (один и тот же эпизод лечения, хронологические цепочки).
- В каждой заметке есть блок обратных ссылок: из него видно, какие ещё документы на неё ссылаются.
