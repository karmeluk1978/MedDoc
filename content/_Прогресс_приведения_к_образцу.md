# Приведение заметок к образцу

Образцы: `2026-05-25_Биохимия-HELIX` (анализы), `2026-07-10_КТ-ОГК-ОНП-шея_ДИКБ` (инструментальные), `2026-06-09_Консультация-пульмонолог_3ДКБ` (консультации). Служебные файлы (`Динамика по показателям`, `_шаблоны_по_категориям`, `Приём препаратов`, индексы) не трогаем. Заметки лежат в `Медицинские документы/<год>/`.

## Формат

1. frontmatter → `# Заголовок` → реквизиты одним блоком без пустых строк (Учреждение, Пациент, Дата рождения (+возраст), при необходимости Документ/№ заказа/Дата/Врач) → `> [!info] Плановое исследование` → таблицы/текст → `## Заключение` → `> [!note] Источник` → футер `← [[пред]] · → [[след]]`.
2. `[!info]`: что сдано в тот же день, ссылки на пред./след. заметку категории; «плановое» только если назначение есть в документах.
3. Таблицы: Показатель | Результат | Ед. | Референс | Оценка | Δ vs <дата>. ✅/⚠️/⛔ только в «Оценке». Δ: ⬆️/⬇️ (было X), «=», «⚠️ Ухудшение (было X)», «✅ Улучшение (было X)», «—» (не измерялось или несопоставимо). У первой заметки категории Δ нет.
4. Δ — к хронологически предыдущему анализу любого учреждения, по сопоставимым значениям; если показатель не определялся — к последней точке с датой. Два анализа в один день — к предыдущему той же лаборатории.
5. `## Заключение`: `[!success]` (только если есть нормальные факты документа) + `[!warning] Особенности, требующие учёта` (числа и ссылки). Убраны «Пациент», «Динамика», прежнее «Заключение врача».
6. Цепочки ←/→ по категории (материал/тип), без межкатегорийных ссылок.

## Правила достоверности

- Значения только из заметок/сканов. Диагнозы и рекомендации, которых нет в документе, не добавлять; интерпретации («клинически незначимо», «воспаления нет», «готов к операции») убирать.
- «Впервые», «самая ранняя», «максимум» — проверять поиском или убирать.
- Опечатки источника оставлять с пометкой, в Δ не использовать.
- Заглушки (`не_распознано`, `требует_проверки`) не трогать.
- `2023-04-21_H-Pylori_3КБ` — анализ отца; в заметки и цепочки ребёнка не включать. Исключение из шапки также `2026-09-13_Сводка-для-гастроэнтеролога`.

## Приёмы

- Правка: `search_and_replace` с регэкспом от строки возраста «(X лет Y месяцев)» до `[\s\S]*$` (один файл в `scope`, смотреть `files_matched`); кириллицу в путях проверять. Альтернативы `A|B` — только с одинаковой заменой.
- После серии: `find_broken_links` по изменённым файлам; в конце категории — дубли заголовков `(#{1,6} [^\n]+)\n\n\1\n`, двойные `## Заключение`, литеральный `\n`.
- Запасной инструмент — Filesystem MCP (`C:\Хранилище\Хранилище\Медицинские документы\<год>\`).
