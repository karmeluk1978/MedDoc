## Антибиотикограмма — динамика чувствительности к антибиотикам

Строки — антибиотик (по алфавиту), столбцы — дата анализа. S — чувствителен; R — резистентен (устойчив); I — умеренно-устойчив; «—» — антибиотик в этом анализе не тестировался.

```dataviewjs
const order = ["E. coli", "Proteus mirabilis", "Staphylococcus aureus"];
const legend = { "Чувствительный": "S", "Устойчивый": "R", "Умеренно-устойчивый": "I" };
const cell = v => legend[v] ? `<span class="abx abx-${legend[v]}">${legend[v]}</span>` : `<span class="abx abx-N">—</span>`;
dv.container.classList.add("vertical-headers", "abx-t");
const pages = dv.pages('#дисбактериоз')
  .where(p => p.antibiogram)
  .sort(p => p.date, 'asc');

const canon = ["Азитромицин", "Азтреонам", "Амикацин", "Амоксициллин/клавулановая кислота", "Ампициллин", "Ванкомицин", "Гентамицин", "Доксициклин", "Дорипенем", "Имипенем", "Кларитромицин", "Клиндамицин", "Котримоксазол", "Левофлоксацин", "Линезолид", "Меропенем", "Миноциклин", "Нитрофурантоин", "Норфлоксацин", "Оксациллин", "Офлоксацин", "Пенициллин", "Пиперациллин", "Пиперациллин/тазобактам", "Рифампицин", "Тейкопланин", "Тикарциллин/клавуланат", "Тобрамицин", "Хлорамфеникол", "Цефепим", "Цефокситин", "Цефоперазон", "Цефоперазон/сульбактам", "Цефотаксим", "Цефтазидим", "Цефтриаксон", "Цефуроксим", "Эритромицин"];
const alias = { "бензилпенициллин": "пенициллин", "фурадонин": "нитрофурантоин", "тикарциллин/клавулановая кислота": "тикарциллин/клавуланат", "триметоприм/сульфаметоксазол": "котримоксазол" };
const norm = s => { const n = String(s).toLowerCase().replace(/ё/g, "е").replace(/\s*\(.*?\)\s*/g, "").replace(/\s+/g, " ").trim(); return alias[n] ?? n; };
const canonSet = new Set(canon.map(norm));

for (const bact of order) {
  const rows = pages.where(p => p.antibiogram[bact]);
  if (rows.length === 0) continue;
  const rowArr = rows.array();

  // результаты каждого анализа: нормализованное название антибиотика -> S/I/R
  const data = rowArr.map(p => {
    const d = {};
    for (const [k, v] of Object.entries(p.antibiogram[bact])) d[norm(k)] = v;
    return d;
  });

  // полный перечень (38 препаратов, как в заметках) + препараты, которых нет в перечне (если появятся)
  const extra = new Map();
  for (const p of rowArr) {
    for (const k of Object.keys(p.antibiogram[bact])) {
      if (!canonSet.has(norm(k)) && !extra.has(norm(k))) extra.set(norm(k), k);
    }
  }
  const abx = [...canon.map(n => [n, norm(n)]), ...[...extra.entries()].sort((a, b) => a[1].localeCompare(b[1], "ru")).map(([n, k]) => [k, n])];

  dv.header(4, bact);
  dv.table(
    ["Антибиотик", ...rowArr.map(p => `<span class="vh">[[${p.file.path}|${p.date.toFormat("dd.MM.yyyy")}]]</span>`)],
    abx.map(([name, key]) => [
      name,
      ...data.map(d => cell(d[key]))
    ])
  );
}
```

> [!info] Примечания по источникам
> - **E. coli** — данные есть только за 16.11.2022 (ЭКОМЕДСЕРВИС, частичная панель — тестировались только гентамицин/офлоксацин/цефотаксим) и 18.01.2023 (ЛОДЭ, прозаическое описание в заключении, не табличный бланк). После 2023 года антибиотикограмма для E. coli в архиве не встречается.
> - **Proteus mirabilis** — до 2024 включительно ДИКБ тестировала расширенную панель (~20 антибиотиков, преим. резервные/парентеральные препараты: пиперациллин, цефоперазон, карбапенемы и т.д.), тогда как ЛОДЭ (2024 и 2026) использует компактную панель из 8 «стандартных» пероральных/базовых антибиотиков — отсюда разрыв в 2024–2026 и малое пересечение колонок между лабораториями.
> - **Staphylococcus aureus** — впервые протестирован 17.01.2024 (ЛОДЭ); 17.04.2024 (ДИКБ) чувствителен ко всем 21 протестированным антибиотикам (в т.ч. эритромицин, не встречается в панели ЛОДЭ) — отдельная широкая панель, из архива видно постепенное нарастание устойчивости к 2026 году (ванкомицин, оксациллин, цефалоспорины начинают чередоваться между «чувствителен»/«устойчив» от анализа к анализу).
> - 18.08.2026 (ЛОДЭ) нитрофурантоин указан в оригинале под торговым названием «Фурадонин» — в таблице сведён к общей колонке «Нитрофурантоин» для сопоставимости с более ранними точками.
