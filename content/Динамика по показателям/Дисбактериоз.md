# Дисбактериоз — вся динамика по всем показателям

```dataviewjs
dv.container.classList.add("vertical-headers", "dysb-main");
const vh = t => `<span class="vh">${t}</span>`;
const cols = [
  ["E. coli", "ecoli"],
  ["E.coli сниж.", "ecoli_snizhennaya"],
  ["Proteus", "proteus_mirabilis"],
  ["Klebsiella", "klebsiella_pneumoniae"],
  ["Enterobacter", "enterobacter_cloacae"],
  ["St. aureus", "staph_aureus"],
  ["Дрожжи", "drozhzhi"],
  ["Бифидо", "bifido"],
  ["Лакто", "lacto"],
  ["Клостридии", "clostridii"],
  ["Энтерококки", "enterococci"]
];
const pages = dv.pages('#дисбактериоз').sort(p => p.date, 'asc');
dv.table(
  ["Дата", "Учреждение", ...cols.map(c => vh(c[0])), "Отклонения"],
  pages.map(p => [
    dv.fileLink(p.file.path, false, p.date.toFormat("dd.MM.yyyy")),
    p.institution,
    ...cols.map(c => p.values?.[c[1]] ?? "—"),
    p.abnormal ?? "—"
  ])
);
```

## Антибиотикограмма — динамика чувствительности к антибиотикам

Строки — дата анализа, столбцы — антибиотик (по алфавиту). S — чувствителен; R — резистентен (устойчив); I — умеренно-устойчив; «—» — антибиотик в этом анализе не тестировался.

```dataviewjs
const order = ["E. coli", "Proteus mirabilis", "Staphylococcus aureus"];
const legend = { "Чувствительный": "S", "Устойчивый": "R", "Умеренно-устойчивый": "I" };
const cell = v => legend[v] ? `<span class="abx abx-${legend[v]}">${legend[v]}</span>` : `<span class="abx abx-N">—</span>`;
dv.container.classList.add("vertical-headers");
const pages = dv.pages('#дисбактериоз')
  .where(p => p.antibiogram)
  .sort(p => p.date, 'asc');

for (const bact of order) {
  const rows = pages.where(p => p.antibiogram[bact]);
  if (rows.length === 0) continue;

  const abxSet = new Set();
  for (const p of rows) {
    for (const abx of Object.keys(p.antibiogram[bact])) abxSet.add(abx);
  }
  const abx = Array.from(abxSet).sort((a, b) => a.localeCompare(b, "ru"));

  dv.header(4, bact);
  dv.table(
    ["Дата", "Учреждение", ...abx.map(a => `<span class="vh">${a}</span>`)],
    rows.map(p => [
      dv.fileLink(p.file.path, false, p.date.toFormat("dd.MM.yyyy")),
      p.institution,
      ...abx.map(a => cell(p.antibiogram[bact][a]))
    ])
  );
}
```

> [!info] Примечания по источникам
> - **E. coli** — данные есть только за 16.11.2022 (ЭКОМЕДСЕРВИС, частичная панель — тестировались только гентамицин/офлоксацин/цефотаксим) и 18.01.2023 (ЛОДЭ, прозаическое описание в заключении, не табличный бланк). После 2023 года антибиотикограмма для E. coli в архиве не встречается.
> - **Proteus mirabilis** — до 2024 включительно ДИКБ тестировала расширенную панель (~20 антибиотиков, преим. резервные/парентеральные препараты: пиперациллин, цефоперазон, карбапенемы и т.д.), тогда как ЛОДЭ (2024 и 2026) использует компактную панель из 8 «стандартных» пероральных/базовых антибиотиков — отсюда разрыв в 2024–2026 и малое пересечение колонок между лабораториями.
> - **Staphylococcus aureus** — впервые протестирован 17.01.2024 (ЛОДЭ); 17.04.2024 (ДИКБ) чувствителен ко всем 21 протестированным антибиотикам (в т.ч. эритромицин, не встречается в панели ЛОДЭ) — отдельная широкая панель, из архива видно постепенное нарастание устойчивости к 2026 году (ванкомицин, оксациллин, цефалоспорины начинают чередоваться между «чувствителен»/«устойчив» от анализа к анализу).
> - 18.08.2026 (ЛОДЭ) нитрофурантоин указан в оригинале под торговым названием «Фурадонин» — в таблице сведён к общей колонке «Нитрофурантоин» для сопоставимости с более ранними точками.
